# 🚀 Test Automation Tool

A full-stack web application that allows users to upload files, automatically generate test cases, and execute them with detailed results.

🌐 **Live Demo**: https://testing-automation-project.onrender.com

## 📌 Features

- 📂 Upload code or JSON files
- 🤖 Generate test cases (AI + rule-based)
- ▶️ Execute test cases automatically
- 📊 View detailed test results
- 📈 Dashboard with test run history
- 🔍 Inspect individual test case results

## 🛠️ Tech Stack

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Python (Flask)

**Database**
- SQLite

**Deployment**
- Render

## ⚙️ How It Works

1. Upload a file (code or JSON)
2. Generate test cases (AI or simple logic)
3. Execute tests
4. View results and statistics in dashboard
